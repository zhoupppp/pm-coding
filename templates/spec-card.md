# 规格卡模板

> 产品研发 7 步流程 Step 2 强制输出。8 个维度全部填写后才能进入编码。

---

## 规格卡：「{功能名称}」

| 维度 | 内容 |
|------|------|
| **功能名称** | （一句话描述） |
| **用户故事** | 作为（谁），我想要（做什么），以便（达成什么价值） |
| **验收条件** | [ ] 条件 1（Given-When-Then 格式）  [ ] 条件 2  [ ] 条件 3 |
| **边界约束** | 不做什么？数据量上限？并发上限？兼容性要求？ |
| **错误场景** | 网络异常时？数据为空时？权限不足时？超时时？ |
| **成功指标** | （可测量的完成标准，如「API 响应时间 < 200ms」「用户可在 3 步内完成操作」） |
| **风险点** | （可能出问题的地方 + 影响程度 + 发生概率） |
| **回滚方案** | （出问题怎么退回去？回滚步骤？回滚后如何验证？） |
