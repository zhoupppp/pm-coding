# 经验沉淀规则

> 由全局 CLAUDE.md 引用。非平凡任务结束时强制执行。

---

每个非平凡任务结束时，输出结构化沉淀并存入 memory/：

| 沉淀项 | 内容 |
|--------|------|
| 做了什么 | 一句话 |
| 关键决策 | 最重要的技术或方法选择 |
| 踩了什么坑 | 遇到的问题和解决方法 |
| 下次改进 | 如果重做会怎么做 |
| 可复用 | 是否有可复用的模式/代码/模板 |

**存储规则**：沉淀内容自动存入 `~/.claude/projects/{项目名}/memory/`，文件名格式：`learn_{YYYY-MM-DD}_{任务关键词}.md`。如果是跨项目的通用经验，存入全局 `~/.claude/projects/C--Users-EDY/memory/`。

**判断标准**：「非平凡任务」指满足以下任一条件的任务：
- 涉及代码变更（新建或修改文件）
- 涉及对外输出的文档/报告/PPT
- 用户明确要求记录的任务
- 耗时超过 3 轮交互的任务
