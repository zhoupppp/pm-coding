# AI 输出质量管控

> 由全局 CLAUDE.md 引用。所有任务类型适用。

---

### Hallucination 检测信号
出现以下任一信号，立即暂停并验证：
- 引用了不存在的 API / 库 / 文件路径
- 引用了不存在的配置项或命令
- 建议与代码库现状明显矛盾
- 无法在代码库中找到其引用的位置

### 输出置信度标注
- **「确定」**：已验证或可直接验证
- **「推测」**：基于经验判断 → 必须注明验证方法
- **「不确定」**：信息不足 → 必须先提问再回答

### 降级策略
| 场景 | 降级动作 |
|------|---------|
| 连续 3 次输出无法通过验证 | 切换到更保守/更简单的方案 |
| 复杂架构决策 | 输出 2+ 个方案供用户选择，不直接拍板 |
| 安全相关代码 | 强制走 security-reviewer，不自行判断安全 |
| 不确定的推论 | 标注「推测」并给出验证方法 |
