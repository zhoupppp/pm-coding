# 生产级门禁检查清单

> 产品研发 7 步流程的最终门禁（Step 7）。所有检查项通过后才能上线。

---

## 上线前检查清单

### 需求门禁
- [ ] 规格卡所有验收条件已通过测试
- [ ] 「不做什么」边界未被突破

### 代码门禁
- [ ] code-reviewer 无 CRITICAL 或 HIGH 问题
- [ ] silent-failure-hunter 无吞掉的异常
- [ ] 无硬编码密钥/令牌/密码
- [ ] 所有外部调用有超时策略

### 测试门禁
- [ ] Happy Path 测试通过
- [ ] 错误路径测试通过（网络异常、超时、数据为空、权限不足）
- [ ] 核心逻辑覆盖率 ≥ 80%
- [ ] UI 变更已截图留痕（`.test-evidence/`）

### 安全门禁
- [ ] 涉及 P0 数据/认证/支付/加密 → security-reviewer 通过
- [ ] 第三方依赖无已知高危漏洞（npm audit / pip audit）
- [ ] API 响应不泄露数据库错误、堆栈跟踪、内部 IP

### 上线门禁
- [ ] 回滚方案已确认（`templates/rollback-plan.md`）
- [ ] 监控指标已配置
- [ ] 相关文档已更新
- [ ] 生产环境冒烟测试通过
- [ ] 变更已通知相关人员

### AI 质量门禁
- [ ] 无 Hallucination 信号（不存在的 API/文件/配置引用）
- [ ] 不确定的推测已标注置信度
- [ ] 安全相关代码已经 security-reviewer，非 AI 自行判断
