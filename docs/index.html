设计原则

不只是写代码，是交付正确的产品

6 条原则决定 Claude 在每一步的行为——什么优先，什么必须确认。

01

安全优先

不确定的先问，不可逆的先确认。删数据库、推送生产分支必须先通过 P0 确认。

02

正确优先于快速

先确认做对的事，再把事做快。需求模糊时先 5W1H 追问。

03

规格优先于代码

先出 8 维规格卡——定义「完成」长什么样——再写第一行代码。

04

验证优先于信任

AI 生成的代码默认需要验证。Hallucination 检测自动触发。

05

可回滚优先于完美

每次代码变更都有退路。每个功能定义都附带回滚方案。

06

沉淀优先于重复

每个任务结束自动沉淀经验。同一个坑不踩两次。

安装

2 分钟，零外部依赖

克隆仓库，运行脚本，配置 API Key。128 个文件全部内置，不需要额外下载插件。

新用户

# 1. 克隆
git clone https://github.com/zhoupppp/pm-coding.git ~/.pm-coding

# 2. 部署
bash ~/.pm-coding/setup-portable.sh

# 3. 配置 API Key
cp ~/.pm-coding/settings.example.json ~/.claude/settings.json
# 编辑 settings.json 填入你的 Key

# 4. 重启 Claude Code
