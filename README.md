## 它能做什么？

装上之后，你的 Claude Code 会像一个靠谱的产品研发搭档那样工作：

| 你遇到的情况 | 以前 | 现在 |
|------------|------|------|
| 「帮我加个登录功能」 | 直接写代码 | 先问清楚：什么登录方式、给谁用、要不要验证码 |
| 「帮我分析一下竞品」 | 给几段文字 | 调竞品分析框架，出 SWOT + 差异化定位 |
| 「帮我把数据库那个字段删掉」 | 直接删 | ⚠️ 先弹确认：影响范围、回滚方案、等你点头 |
| 「帮我写个 PRD」 | 给个通用模板 | 走产品定义流程，从商业模型到用户故事 |
| 「这个 API 好像不存在」 | 编一个假的 | 🔍 暂停验证，标注不确定 |
| 「明天要给投资人 PPT」 | 走普通流程 | 感知时间压力，直接跳到输出 |

**一句话：你不需要每次都说「先别写代码，先想清楚」——规则已经替你说了。**

## 快速开始

### 新用户（2 分钟）

```bash
# 1. 克隆
git clone https://github.com/zhoupppp/pm-coding.git ~/.pm-coding

# 2. 部署
bash ~/.pm-coding/setup-portable.sh

# 3. 配置 API Key
cp ~/.pm-coding/settings.example.json ~/.claude/settings.json
# 编辑 settings.json，填入你的 API Key

# 4. 重启 Claude Code，完成。
```

首次启动后，Claude 会自动检查配置完整性。缺失的依赖会明确告知你，不会静默失败。

### 验证安装

在新会话中输入：

```
请读取 ~/.claude/CLAUDE.md 的第一行标题
```

预期输出：`# 生产级 AI 产品研发引擎`

### 老用户（更新到最新版）

```bash
cd ~/.pm-coding && git pull && bash setup-portable.sh
```

## 工作场景

| 类型 | 当你需要…… | Claude 会…… |
|------|-----------|------------|
| 🧭 **产品定义** | 市场调研、竞品分析、PRD、GTM 规划 | 5 阶段：调研→分析→洞察→定义→验证 |
| 🏗️ **产品研发** | 功能开发、Bug 修复、架构变更 | 7 步：澄清→规格→架构→编码→测试→安全→上线 |
| 📊 **数据分析** | 数据清洗、Excel、图表 | 5 步：需求→获取→清洗→验证→报告 |
| 📈 **工作汇报** | PPT、周报、可视化报告 | 4 步：受众→结构→内容→视觉 |
| 📝 **会议纪要** | 客户会议、内部评审 | 3 步：输入→提炼→行动项 |
| 🔍 **轻量调研** | 快速了解概念、技术选型 | 4 步：范围→收集→验证→洞察 |
| 📚 **学习研究** | 学新技术、理解原理 | 3 步：问题→解释→应用 |
| ✉️ **文档草拟** | 邮件、通知、方案 | 直接输出 + 脱敏 |
| 💬 **快速咨询** | 问定义、快速确认 | 直接回答 + 置信度 |

如果 Claude 判断错了场景，用命令手动切换：`/pm` `/dev` `/data` `/report` `/quick`。

## 安全机制

| 触发条件 | Claude 的行为 |
|---------|-------------|
| 删除数据库字段 | ⚠️ P0 封控：先弹确认（操作/影响/风险/回滚） |
| 推送生产分支 | ⚠️ 同上 |
| 修改支付/认证代码 | ⚠️ 强制走 security-reviewer |
| 引用不存在的 API | 🔍 Hallucination 检测：暂停验证，不硬编 |
| 不确定的推测 | 📝 标注置信度 + 给出验证方法 |

## 原则

1. **安全优先** — 不确定的先问，不可逆的先确认
2. **正确优先于快速** — 先确认做对的事，再把事做快
3. **规格优先于代码** — 先定义「完成」长什么样，再写代码
4. **验证优先于信任** — AI 生成的代码和结论默认需要验证
5. **可回滚优先于完美** — 每次代码变更都有退路
6. **沉淀优先于重复** — 同一个坑不踩两次

## 常见问题

<details>
<summary><strong>Q：会让 Claude 变得很啰嗦吗？</strong></summary>
不会。轻量场景走轻量流程。/quick 一键跳过。只有代码变更或产品决策才会走完整门禁。
</details>

<details>
<summary><strong>Q：和默认 Claude Code 有什么区别？</strong></summary>
默认的 Claude 收到任务直接执行。这套配置会先判断任务类型、选流程、该澄清的澄清、该确认的确认——因为目标是「交付正确的产品」，不是「快速出代码」。
</details>

<details>
<summary><strong>Q：我能只装部分功能吗？</strong></summary>
可以。setup-portable.sh 会检查依赖并告诉你缺少什么。规则文件是独立的，你可以删掉不需要的 rules/common/ 文件。
</details>

<details>
<summary><strong>Q：新电脑怎么迁移？</strong></summary>
克隆仓库 → 运行 setup-portable.sh → 手动复制 settings.json。2 分钟搞定。
</details>
